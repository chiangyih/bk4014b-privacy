BK 4014B 控制與監看 App 隱私權政策

生效日期：2026 年 10 月 29 日（適用於 1.0.4.0）

本隱私權政策適用於「新化高工資訊科 BK4014B 控制與監看」（以下稱「本 App」）。本 App 由 Tseng 發行，是用於 BK 4014B 訊號產生器之教學、模擬、狀態讀取與基本控制的 Windows 桌面應用程式。

我們處理的資料

本 App 不要求建立帳戶，也不要求提供姓名、電子郵件、位置、聯絡人、相片或財務資料。設定檔名稱與說明是使用者自行輸入的文字，匯入的 JSON 也可能包含這類文字；若您在其中填入個人資訊，本 App 會隨設定檔在本機處理及保存這些內容。使用設定檔功能不需要填入個人資訊。

為提供本機功能，本 App 會處理可用及已選取的 COM 埠名稱、使用者輸入的波形參數，以及所連接儀器回覆的製造商、型號、韌體版本、可能的儀器序號、設定值、輸出狀態、工作模式、時間戳、命令回覆與錯誤資訊。

使用目的與儲存

上述技術資料用於列出序列埠、連接使用者選定的 BK 4014B、顯示或控制儀器狀態、執行模擬，以及在目前工作階段顯示操作與錯誤紀錄。工作階段操作與錯誤紀錄保留於程式記憶體中，本 App 不會自動將這些紀錄另存為日誌檔。

使用者按下儲存或匯入時，本 App 會持久保存實驗設定檔：名稱、說明、波形與參數、單位、4014B 型號、格式版本、設定檔識別碼及儲存時間。設定檔不是儀器回讀或命令紀錄，也不包含 COM 連線資訊或開啟輸出指令。載入只更新草稿與設定預覽，不自動套用或開啟輸出。

設定檔的邏輯儲存位置為 %LOCALAPPDATA%\Bk4014B\Profiles，檔名使用設定檔識別碼。Microsoft Store／MSIX 安裝版可能由 Windows 將此位置重新導向至該套件的本機資料區，實際位置依 Windows 與安裝方式而定。檔案使用一般 JSON 格式，本 App 不提供設定檔加密或自動到期刪除。

匯入只讀取使用者明確選定的 JSON，驗證後建立新的本機設定檔；不修改匯入來源檔。匯出將選取的已儲存設定檔寫入使用者選定的位置；若取代既有檔案，選擇器會要求覆寫確認。關閉 App 不會刪除已保存的設定檔、匯入來源或匯出副本。

留存、移除與使用者控制

設定檔會保留至您透過 Windows 檔案管理移除，或由 Windows 依安裝方式清理；目前版本沒有 App 內刪除設定檔按鈕。可先關閉 App，再透過檔案總管管理上述本機資料位置的 JSON；MSIX 版如有重新導向，請使用該套件的實際資料位置，或透過支援頁面詢問位置。

匯入來源、匯出副本、同步服務的版本、資源回收筒及備份可能分別留存，須在各自的位置或服務另行管理。不要僅以關閉或移除 App 判定所有副本均已刪除。發行者不會透過本 App 收到或保存這些檔案，因此無法代您存取或刪除裝置或其他服務上的副本。

網路傳輸、同步與其他服務

本 App 本身不提供雲端上傳或同步服務，不會將設定檔、儀器資料或使用者輸入透過 App 傳送給發行者；不包含廣告、使用情況分析、追蹤或開發者遙測，也不出售使用者資料。

您選取的匯入／匯出位置可能是 OneDrive、其他雲端同步資料夾或網路位置；Windows、同步或備份軟體可能依您的設定傳輸、保存或分享檔案。這些服務的資料處理及保留期限依其帳戶設定與隱私政策決定，並非本 App 傳送給發行者的資料。

Microsoft Store、Windows 或裝置驅動程式也可能依各自的條款與隱私權聲明處理下載、授權、當機或系統診斷資料。若您自行透過支援網站提供內容，該網站會依其政策處理；本 App 不會自動上傳支援附件。

裝置存取與兒童隱私

本 App 會列出 Windows 偵測到的 COM 埠，只有在使用者選擇埠並按下連線後才與該序列埠通訊。使用者可中斷連線或關閉 App；這不會刪除已保存的設定檔，也不代表儀器輸出已停止。

本 App 不要求帳戶，也不針對兒童要求個人資訊。使用者自行輸入或匯入的文字仍依上述本機儲存、留存及控制方式處理。

政策更新

本政策已反映 1.0.4.0 的本機設定檔與 JSON 匯入／匯出。若後續版本改變資料處理方式，本政策會隨之更新，最新版本公布於本政策頁面。

聯絡方式

隱私相關問題可透過公開支援頁面聯絡發行者 Tseng：https://github.com/chiangyih/bk4014b-privacy/issues。該頁面為公開頁面，請勿張貼不希望公開的個人資訊或設定檔內容。

Privacy Policy for the BK 4014B Controller and Monitor App

Effective date: October 29, 2026 (applies to version 1.0.4.0)

This Privacy Policy applies to “新化高工資訊科 BK4014B 控制與監看” (the “App”). The App is published by Tseng and is a Windows desktop application for teaching, simulation, status readback, and basic control of a BK 4014B signal generator.

Data processed by the App

The App does not require an account or ask for a name, email address, location, contacts, photos, or financial information. Profile names and descriptions are text supplied by the user, and imported JSON may also contain such text. If you include personal information in that text, the App processes and saves it locally as part of the profile. Personal information is not needed to use profiles.

For its local functions, the App processes available and selected COM port names, waveform parameters entered by the user, and technical information returned by the connected instrument. This may include manufacturer, model, firmware version, instrument serial number if supplied, settings, output state, operating mode, timestamps, command responses, and error information.

Purpose and storage

The App uses technical information to list serial ports, connect to the user-selected BK 4014B, display or control the instrument, run the simulation, and display operation and error records during the current session. Session operation and error records are held in application memory; the App does not automatically save them as log files.

When you save or import, the App persistently stores an experiment profile containing its name, description, waveform and parameters, units, 4014B model, format version, profile identifier, and save time. Profiles are not instrument readbacks or command logs and contain no COM connection information or output-on instruction. Loading updates only the draft and settings preview; it does not automatically apply settings or turn output on.

The logical profile location is %LOCALAPPDATA%\Bk4014B\Profiles, with filenames based on profile identifiers. For Microsoft Store/MSIX installations, Windows may redirect this location to the package's local data area; the physical location depends on Windows and the installation. Files use ordinary JSON. The App does not encrypt profiles or automatically expire them.

Import reads only the JSON file you explicitly select and creates a new local profile after validation; it does not modify the source file. Export writes the selected saved profile to the location you choose; the picker requests confirmation before replacing an existing file. Closing the App does not delete saved profiles, import source files, or exported copies.

Retention, removal, and user controls

Profiles remain until you remove them through Windows file management or Windows cleans them up according to the installation type. This version has no in-app profile deletion button. Close the App before managing JSON files in the local data location through File Explorer. If an MSIX installation redirects the location, use the package's actual data location or ask through the support page for help locating it.

Import sources, exported copies, sync-service versions, recycle bins, and backups may be retained separately and must be managed in their respective locations or services. Closing or uninstalling the App does not establish that every copy has been deleted. The publisher does not receive or retain these files through the App and cannot access or delete copies on your device or other services for you.

Network transmission, synchronization, and other services

The App itself provides no cloud upload or synchronization service and does not send profiles, instrument data, or user input to the publisher through the App. It contains no advertising, usage analytics, tracking, or publisher telemetry and does not sell user data.

An import or export location you choose may be OneDrive, another cloud-synchronized folder, or a network location. Windows, synchronization, or backup software may transmit, retain, or share files according to your settings. Those services handle data and retention under their own account settings and privacy policies; this is not data sent by the App to the publisher.

Microsoft Store, Windows, or device drivers may also process download, licensing, crash, or system diagnostic data under their own terms and privacy statements. If you voluntarily provide content through the support website, that website handles it under its policies; the App does not automatically upload support attachments.

Device access and children's privacy

The App lists COM ports detected by Windows and communicates with one only after you select a port and connect. You may disconnect or close the App; doing so does not delete saved profiles or establish that instrument output has stopped.

The App does not require an account or specifically ask children for personal information. Text that users enter or import is still handled under the local storage, retention, and controls described above.

Changes to this policy

This policy reflects local profiles and JSON import/export in version 1.0.4.0. It will be updated if later versions change data handling. The latest version is published on this policy page.

Contact

For privacy questions, contact the publisher, Tseng, through the public support page: https://github.com/chiangyih/bk4014b-privacy/issues. That page is public; do not post personal information or profile content that you do not want to make public.
